# Kin Relay

Your phone and your PC, finally acting like they belong to the same person. Any brand.

Kin Relay links an Android phone and a Windows PC: files, text, links and clipboard, with nothing to open. The plan is in [docs/README.md](docs/README.md). Start there.

## Repo layout

```
docs/       the plan
android/    Android app (Kotlin, Jetpack Compose)
desktop/    Windows app (the winner of the Phase 0 stack comparison)
spikes/     Phase 0 throwaway experiments
protocol/   example messages and test vectors shared by both apps
tools/      scripts for soak tests and benchmarks
```

Folders appear as the phases need them.
